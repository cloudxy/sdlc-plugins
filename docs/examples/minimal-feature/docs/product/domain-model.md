# 领域模型 · 租户控制台

## 1. 概念

| 概念 | 是什么 | 不变量 |
|---|---|---|
| Tenant | 租户 | id 唯一 |
| AuditEvent | 一次已发生的管理操作 | 必须属于一个租户；发生时间必须带时区 |
| 导出结果 | 一次读模型，不是存储实体 | 只包含该管理员所属租户的事件；时间列是 UTC；不落库 |

成员角色只用于判断谁可以调用导出。本切片不扩展成员的生命周期。

## 2. 导出不变量

1. 返回 CSV 时，每一行的租户都等于调用者的租户。
2. 拒绝时，调用者拿不到 CSV 正文，也拿不到其他租户的事件 id。
3. `occurred_at_utc` 是事件时间换到 UTC 后的文本，不保留偏移量。

## 3. 和表的关系

`erd.dbml` 里有 `tenant` 和 `audit_event`。没有 `export` 表。行上限 10000 是导出的规则，不是表上的约束。
