# 功能地图 · 租户控制台

## 1. 核心价值路径

租户管理员遇到追问 → 导出本租户审计 CSV → 在表格里看到 UTC 时间与本租户事件。

## 2. 现在 / 以后

| 功能 | 层级 | 作用 | 状态 |
|---|---|---|---|
| 导出租户审计日志 CSV | 现在 | 把「拿到只含本租户的审计文件」做成一次调用 | 本样例，本地已验证 |
| 按动作筛选后再导出 | 以后 | 文件更短 | 本切片不做 |
| 导出任务异步通知 | 以后 | 行数很大时不必占着连接 | 超过 10000 行本切片直接拒绝 |

## 3. 关键旅程

管理员在本租户内发起导出，得到 CSV。失败时没有文件正文：无权限、跨租户行、没有时区的时间、超过 10000 行。
