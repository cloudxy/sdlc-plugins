# 架构 · 租户控制台

## 1. 现在有什么

审计行已经按租户落在 `audit_event`。控制台 API 进程负责鉴别调用者属于哪个租户。本样例不描述一套尚未部署的生产拓扑，只描述这个切片依赖的边界。

## 2. 本切片的位置

导出是 API 进程里的一个纯函数：`src/audit_export.py` 的 `export_audit_csv`。它不监听端口，不新开服务，不写新表。调用方传入已鉴权的 actor 和本查询读到的事件；函数决定拒绝还是返回 CSV 文本。

## 3. 边界

| 边界 | 谁负责 | 不变量 |
|---|---|---|
| 调用者是不是该租户的管理员 | 函数入口 | 不是则拒绝，且不返回 CSV |
| 事件属于哪个租户 | 函数逐行检查 | 出现其他租户的行则整次拒绝 |
| 时间 | 函数写成 UTC | 没有时区的时间拒绝，不按本地钟猜测 |

## 4. 不做的结构

不增加导出任务表，不增加对象存储。10000 行以内一次返回文本；超过则拒绝。异步导出是以后的事，不在本切片假装已经有队列。
