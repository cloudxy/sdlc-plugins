# 拒绝清单

这里记录插件**有意不做**的事：结论、理由、来源，以及什么样的新证据会让我们重新考虑。

作用是避免同一个提议每轮都被重新提出，也避免已拒绝的做法悄悄混进方法文本。会话诊断（sdlc-eval diagnose）中落点为「out of scope」的发现，确认后写到这里。

重新考虑的方式：拿到条目里写明的证据（通常是 `scripts/behavior_smoke.py` 的对照运行），再按 `maintainers/README.md` 的流程修改方法。不要只凭理由更充分就推翻。
