# 方法场景评测

输入为五个合成任务，写入仅限独立临时输出目录，未授权生产或网络操作。A本地媒体；B跨身份分类/卡片；C旧服务排空；D保留已批准CDN的研究反例；E下载/保存反馈与复制/手势证据边界。维护者判据在各场景执行前单独固定，评测者未接收预期答案。

- 实际输出：[outputs](outputs/README.md)，各场景commands.json保留读取/执行及源摘要；历史命令及A的原样合成脚本保留当时的临时输入位置，属于执行证据，不是插件运行入口；重放须使用归档输入重建对应夹具。
- 判断：[criteria-and-judgments.json](criteria-and-judgments.json)。五个场景满足本次范围内的判据；仅记 evaluated，不作新旧对照收益结论。
- 文本绑定：[method-hashes.json](method-hashes.json)，所有实际读取的方法摘要与候选一致。
- A的离线合成验证包括错误ETag负例退出1、修正后14检查退出0；不是视频播放、HTTP或真实项目集成。
- [generic-validator-compatibility.json](generic-validator-compatibility.json)记录通用校验器对既有when_to_use扩展的基线/候选同类拒绝；保留SDLC协议，按原生维护检查验证。

本轮不宣称原生SDLC角色已在各宿主激活、模型训练、生产部署或真人体验验收。
