# 受阻诊断

所有诊断先服从来源访问合同：ToS、授权 API、限速与已批准的访问预算。这与 [collect/SKILL.md](../SKILL.md) 的爬虫句、外部来源步骤，以及 [anti-scraping-playbook.md](anti-scraping-playbook.md) 一致。下面只解释拦截，不规避风控或配额。

不得打码（含 2captcha / anti-captcha），不得用 UA 轮换或 UA 池规避风控，不得用住宅或数据中心代理池规避封禁。出现验证码或其它访问门控时，暂停受影响操作，留下页面与响应证据，走授权通道或人工升级。

## 判定：被哪种方式拦截

| 症状 | 可能原因 | 应对 |
|---|---|---|
| HTTP 403 / 429 | 频率限制或出口被拒 | 在已批准预算内降速。仍失败则暂停受影响操作并留证。只用合同已允许的出口 |
| HTTP 200 但内容是验证码 | 访问门控 | 暂停、留证，走授权通道或人工升级。不得打码 |
| HTTP 200 但内容与预期不同 | 字段变化，或数据由 JS 加载 | 先找合同允许的 API。Playwright 只在合同允许的渲染范围内使用 |
| 返回空数据但无错误 | 选择器失效，或会话/标识不完整 | 核对已声明的客户端标识、Cookie 与响应证据。不得换 UA 试探 |
| 连接被重置 | 传输失败或出口被拒 | 降低并发，留证，暂停受影响操作。握手差异只用来解释原因，不得模拟 TLS 指纹规避风控 |

## 处置顺序

合同不允许的级别不做。

1. **限速降档**：按来源约定调高 `DOWNLOAD_DELAY`（增大请求间隔）、开启 `AUTOTHROTTLE`、降低单域名并发。
2. **已声明客户端标识**：同一会话保持项目声明的一个 `USER_AGENT`。用它做兼容排查，确认 403 是否来自默认客户端标识。
3. **已授权会话**：使用合同允许的登录态，并维持该会话的 Cookie。不得为绕过限制注册或轮换账号。
4. **授权出口**：只用合同写明的出口。没有写明时，暂停并请负责人升级，不自建代理池。
5. **JS 渲染**：仅当合同允许、且授权 API 没有这份数据时，才用 Splash 或 Playwright。
6. **访问门控**：暂停、留证、授权通道或人工升级。

## 配置

项目已有 settings 时以项目为准。这里只给出合同内的最低项。

```python
# 限速：按来源合同与已批准预算降档
DOWNLOAD_DELAY = 2
AUTOTHROTTLE_ENABLED = True
# 已声明的一个客户端标识。同一会话保持不变。
USER_AGENT = '<项目声明的一个客户端标识>'
```

不挂 UA 轮换中间件，不在设置里写代理池地址。合同若写明单一授权出口，用项目配置里的那一个出口。

## 监控

下列数字是示例起点，不是通用默认值。真实阈值按预期流量和新鲜度 SLA 设定，与 [collect/SKILL.md](../SKILL.md) 的告警句以及手册末节一致。

- 连续零条目（示例：连续 3 次）→ 告警，先核对是否被拦截
- 成功率低于约定（示例：< 80%）→ 告警
- 响应时间高于约定（示例：> 10s）→ 告警，降低并发或检查网络

## 数据源适配

| 源类型 | 提取方式 | 注意 |
|---|---|---|
| 静态 HTML | CSS/XPath 选择器 | 先看 robots.txt 与 ToS |
| JSON API | 直接解析 JSON | 使用授权 API 与其认证 |
| JS 渲染页面 | Splash/Playwright | 仅合同允许的渲染范围 |
| RSS/Atom | feedparser | 来源提供订阅时优先用它 |
| 分页 | URL 模式或授权的 AJAX | 有授权 API 时直接调用 |
