# 数据源分析模板

## 基本信息
- 目标站点：{URL}
- 数据类型：{HTML / JSON API / RSS / 需 JS 渲染}
- 更新频率：{实时 / 每小时 / 每日 / 每周}

## 技术分析
- robots.txt：{允许 / 禁止 / 部分允许}
- 观察到的访问限制：{无 / UA 检测 / IP 封禁 / JS 渲染 / CAPTCHA / 指纹检测}（只记录现象；应对遵守下面的访问合同）
- 数据提取方式：{CSS 选择器 / XPath / JSON 解析 / Playwright}
- 分页方式：{URL 参数 / POST / 无限滚动}

## 数据 Schema
| 字段 | 类型 | 必填 | 提取方式（选择器/API 字段名） |
|---|---|---|---|
| url | string | ✅ | response.url |
| title | string | ✅ | CSS: h2::text |
| price | float | | CSS: .price::text → re_first(r'[\d.]+') |

## 采集策略
- 访问合同：{ToS / 授权 API / 限速与已批准预算；不允许的手段不采用}
- DOWNLOAD_DELAY：{按合同与预算的秒数}
- 并发：{按合同与预算的请求/域名}
- 出口：{合同写明的授权出口 / 不需要；不得用住宅或数据中心代理池规避封禁}
- 客户端标识：{项目已声明的一个标识；不得用 UA 轮换或 UA 池}
- JS 渲染：{不需要 / 仅在合同允许的渲染范围内使用 Playwright}
- 访问门控：{无 / 出现验证码或权限门时暂停、留证、走授权通道或人工升级；不得打码}
- 预计耗时：{N}分钟/全量

## 风险评估
- 被封风险：{低/中/高}
- 数据变化频率：{低/中/高}
- 处置：{降速 / 暂停留证 / 授权通道或人工升级}

## 恢复、幂等键与主数据对账契约（持久任务、共享依赖或分段交付时必填）
- **幂等键唯一约束（Idempotency Key Contract）**：{锁定 `url_key` / `url_hash`（跨批次作业锁定 `(job_id, url_key)`）数据库唯一约束 + `ON CONFLICT DO NOTHING` / 确定性幂等归并（将至少一次投递收敛为有效恰好一次 `effectively-once`）；内容变更由 `content_hash` 独立判定}
- **持久化恢复源（禁内存下标恢复）**：{崩溃/重启后严格从持久化任务表、去重表与重试队列恢复待采差集，**严禁依赖 worker 进程内循环下标（loop index）或内存页码续跑**}
- **任务身份与接管**：{领取、pending/租约、等待/回队、完成或死信；中断与到期后的回收者及提交校验}
- **主数据映射 SSOT 与上下文回显对账（Master Data Mapping & Context Echo Reconciliation）**：{品牌/实体/行政区划映射（如 `brand_id`、省市编码）的**唯一权威事实源（SSOT）路径**与对账规则；落库提交前强断言「请求参数实体/地区/时间窗 == 响应载荷回显实体/地区/时间窗 == 当前活跃持久化断点/租约归属」，隔离迟到包与串号}
- **UI 交互与底层采集回执解耦及失败入队**：{区分 DOM 点击成功与底层 API 载荷获取成功；拦截被点击掩盖的 HTTP `403`/`429`/`5xx` 或业务错误 JSON，向重试/死信队列持久化写入结构化 `error_code`、`request_id` 与 `retryable`（`true/false`）标记}
- **发布条件**：{必需单元；合法空结果（`confirmed-empty`）、缺失与部分结果；是否要求多结果一起可见}
- **交付与确认**：{staging → published → landed 的实际边界；稳定 ID、去重/重放窗口、清理顺序；引用存储契约}
- **失败与预算**：{证据、共享范围、重试/暂停、准入预算、背压、恢复条件；非关键诊断降级}
- **验证与已知边界**：{输入/代码版本、环境、原始证据、未验证影响及负责人/复审条件}
