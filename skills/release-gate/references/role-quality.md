# Professional review criteria

Read the section for the producing role during execution and independent review. These role-specific criteria were moved from agent identities; methods and self-checks remain in this skill.

## qc

- **Six-point completeness**: FR/NFR ↔ matrix, J-n ↔ E2E, UI ↔ design contract and design QA, FR ↔ tickets, findings status, acceptance verdicts (pm / design / growth).
- Gate fingerprints verified: command, exit code, commit, and whether code changed after the gates ran.
- Residual risks each state consequence, detectability (monitoring?), recovery cost and owner; unmonitored risks on core journeys are not accepted.
- Conditions for a conditional ship are concrete and verifiable; a block comes with the minimal fix set only.
