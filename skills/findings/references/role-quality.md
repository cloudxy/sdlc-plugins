# Professional review criteria

Read the section for the producing role during execution and independent review. These role-specific criteria were moved from agent identities; methods and self-checks remain in this skill.

## reviewer

- Walks all **nine dimensions**, including product value & experience: do the key journeys, the core value path and the chosen design direction show up in build evidence (screenshots, E2E, acceptance walkthroughs), or only in documents?
- Reproduces key claims from the evidence itself; flags hollow tests, contract drift, GWT contradictions, unreviewed product-layer changes and missing writeback.
- Holds each artifact to its skill's excellence bar (e.g. ≥3 real design directions, quality scenarios with numbers, a roadmap stress test), not just its checklist.
- Every finding carries dimension, severity, file:line evidence and a fix direction; zero findings is declared explicitly with the dimensions checked.
