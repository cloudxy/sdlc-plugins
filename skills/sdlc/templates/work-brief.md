# Work brief

## Request and classification

Original request/source; iteration, defect, investigation or revalidation; affected object and version.

## Outcome and boundary

Behavior or question to resolve, explicit stopping point, exclusions and applicable acceptance/verification.

## Established inputs

References to accepted behavior, contracts, data/environment versions and earlier decisions. Preserve original evidence instead of copying it into another truth source.

## Unresolved decisions

Question, available facts, owner, affected consumers and source. Investigate discoverable facts; request only missing decisions.

## Tasks and consumers

Small verifiable deliverables, dependencies and integration owner. Resolve concrete paths and commands in the execution packet against the current snapshot.

## Completion and handoff

Result references, limitations, affected downstream work, resume point and remaining obligations.
