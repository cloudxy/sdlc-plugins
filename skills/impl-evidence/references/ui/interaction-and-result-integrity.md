# 点击链、预览与结果的完整性

用于已有菜单、媒体选择、生成结果、历史库或配置卡的修改；沿现有框架与状态权威实现，不要求新增组件库或 store。

## 从输入事件走到操作结果

失焦、pointerdown、click 与关闭处理会相互影响。复现真实事件顺序再修：例如 `focusout.relatedTarget` 为空，不足以证明焦点已移到菜单外；立即隐藏目标可能抢在 click 之前。核父子元素、外部点击、Escape、鼠标/键盘激活与焦点归位，而不只测按钮处理函数。全局监听器、observer、定时器随当前实例注册和清理，不能进入无关页面后仍响应。

对跨页绿线、边框或残留提示，检查当时焦点元素、盒子尺寸、overflow、叠层与伪类。用可区分的探测排除进度/状态假设；若是结构宿主命中全局 `:focus-visible`，只调整已定位的宿主，保留按钮和输入控件的可见焦点。

## 每种媒体表示有自己的结果

参考图、组合预览、生成结果与历史快照各自标明状态归属和写入者。打开/关闭“查看拼图”只改变其预览，不写生成结果；没有生成时也不能把参考组合填成结果。验证重复打开、关闭、预览失败及各自下载对象，不能只看两张图都能显示。

切换主图、备份或角度后，展示、下载、引用和删除使用同一成员及不可变版本；不要把分组行的版本代替当前成员版本。按服务端权限显示管理操作，隐藏控件不能替代 API 鉴权。

调整历史记录的导航位置时，复用既有读写入口。放到“官方资产”页面不等于转为共享服务端资产；浏览器存储、账号隔离、跨设备范围和保留策略沿真实契约说明，不复制第二份历史，也不增加未授权截断。

## 列表请求的生命周期

沿设计契约分别实现自动续载和手动加载；记录首批、追加及模式/筛选重置规则。单次在途、单调推进的 cursor、适当去重和实例/身份/筛选版本检查共同防止重复与迟到响应。旧响应不能进入新分类，清理不能误作用于新实例的 observer。

续载失败保留已显示条目、筛选与 cursor；自动加载暂停，用户明确重试后从原 cursor 继续。首屏失败、真实空集、追加中、全部加载完分别呈现，不能永久停在“加载中”或把失败显示为“暂无”。剩余数与单位来自当前查询的 total / 已载入量，不从本页数量推测全库。

## 配置状态与布局

当前通道的选择、保存、就绪灯、参数校验和生成 payload 使用同一身份；订阅授权和 API Key 模式分别校验。切换、查看或刷新状态保留另一模式已有配置，不因订阅模式而要求 API Key，也不把 CLI 凭据复制到浏览器。

复用父容器时检查嵌套留白、最大高度与全局按钮规则。实际窄屏重载并切换分类，确认当前项、浮条的所有动作及关闭按钮可见；必要时让浮条分行，并给尾部卡片留足空间。配置相似不代表行为相同，最终仍按 [后端授权边界](../api/provider-authorization.md) 的能力契约核对。
