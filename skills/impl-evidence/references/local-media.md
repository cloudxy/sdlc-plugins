# 本地资源从原字节到真实消费者

当已接受的需求包含资源本地化、离线展示或完整媒体复刻时读取。普通托管产品仍沿其已接受的存储/CDN 策略；本方法不授权采集无关内容或改变发布范围。

## 三个身份各司其职

1. **来源与固定业务引用**：原对象、版本、来源及其契约摘要，用于追溯和恢复。
2. **媒体字节**：实际文件的内容摘要、长度、类型和必要的子资源；源视频、截帧封面和转码结果分别标识。
3. **显示/下载消费者**：列表、详情、浮层、预览与下载真正请求的路径和版本。

显示地址改为本地，不自动授权改写已固定的业务快照、请求摘要或历史引用。可由稳定资源身份映射到本地字节；是否更换规范字段由契约所有者决定。来源 URL 可作追溯，本地化交付的消费路径要实际读取本地文件。

## 按本次接口分工实现

- 先核完整资源集合与关系：分页、隐藏详情、脚本内嵌图片及媒体依赖都可能独立于列表。沿既有媒体根目录保存原字节；转换是另一份有来源的新产物，不冒充原文件。
- 将资源身份、内容摘要、长度、类型和本地对象位置纳入可复核清单。传输完整后校验，再发布可读位置；中断或摘要不符时保全既有好文件，按既定恢复方式继续。
- 已要求本地的资源，缺失/损坏按约定显示失败或恢复入口；不自行改成外链回退。恢复下载属于显式操作，读取接口不接受任意 URL 后即刻联网代取。
- 前端核列表、详情、预览和相关下载的真实地址，含 CSS 与图像错误回调；只替换主卡片仍可能留下其他远程消费者。媒体装饰资源不因展示而成为生成输入。
- 后端沿已配置存储边界按资源身份读取文件，限制路径逃逸。媒体若需要拖动播放，检查实际框架的 HEAD/Range/条件请求支持及响应内容；不用“GET 200”代替可播放/可定位。
- 安装包须含新增索引和代码/维护入口；运行媒体按项目部署策略随媒体目录保存/备份。只在开发目录能读到的文件，不算安装路径已交付。

## 校验要对应当前字节对象

ETag 是缓存验证标识，不保证是内容 MD5。先确认提供方对当前表示的语义；动态截帧、压缩、分段/多段上传等可能返回与实际响应字节不同含义的标识。语义不明时保持不透明，使用可验证的传输长度、固定内容摘要和解码检查；不要把校验器假设失败直接判作资源损坏。

保留检查失败、排查及修正后的结果。若修的是校验器，重查受影响集合；已通过且检查依据未变的对象无需因修另一类校验器重新执行昂贵检查。

## 交付证据

按本次需求留清单覆盖、原文件完整性、可用解码、实际本地接口及用户入口消费证据。视频可包括首尾分段与实际播放。模拟 DOM 不能证明浏览器取了本地字节，技术解码不能证明真人审看或专业内容质量；未验设备/范围单列。
