# 供应商授权与实际能力

适用于已接受的 API Key、订阅 CLI 或其他本机授权通道接入。沿当前供应商的官方资料、实际安装版本与本应用适配器核对能力；订阅名称、登录成功或宿主可用不自动授予 API 或另一个进程相同能力。

## 贯穿同一通道的接线

核同一个通道 ID 的：配置登记 → 授权状态 → 服务端允许列表 → 请求解析/校验 → adapter 分派 → 真实输出接收 → 前端结果消费。补配置卡但漏服务端分派，会出现“已授权”后仍索要另一种 Key 或报不支持通道。

分别记录凭证存在、登录有效、通道被当前服务支持、一次真实调用成功；每项证据只支持对应声明。状态灯与预检消费同一能力判断，未知模式不能冒认为已就绪。用户要完成调用时，“只登记授权”不能充当整链完成。

订阅和按量 API 各用所属凭证与计费路线；未经明确授权，不自动回退或互换。保持另一模式的 Key、端点、模型等已有配置，凭据由原所有者/CLI 管理，不搬进日志、源码或浏览器状态。

## 运行环境与输出边界

- 先区分磁盘已配置但进程未加载、CLI 缺失/升级中、未登录、权限阻断、请求解析失败和供应商拒绝。只核凭证存在与加载位置，不回显值；已返回认证失败时，重复加载配置不能证明凭证有效。
- 工具自身认证失败与目标供应商认证失败分别归因。对用户返回可操作的稳定错误分类，诊断原文脱敏后留私有证据，不能用“没有图片”覆盖所有上游错误。
- 按安装版本核 CLI 参数和帮助；可变长图片参数可能吞掉后面的 prompt，必要时用该 CLI 支持的参数终止符区分。传参为独立 argv，不拼可执行 shell 文本；环境、工作目录、超时和可用工具沿获准边界收窄。
- 成功输出须能归于本次调用，路径经规范化后处于获准输出目录，文件可读取且类型符合契约；旧文件、越界路径、未知输出或只有成功退出码，都不能替代本次有效产物。
- 区分无消费的预检与真实付费用量。用既有结果验证展示时不另发生成；一次实际请求失败后沿原因和授权的重试策略处理，不为拿到通过结果反复消耗或偷偷改通道。失败保留先前有效结果，并明确它不是本次新结果。

凭据、账号、目录与数据库连接是项目配置；维护 Skill 不把某台机器的具体路径或某版本模型名变成通用默认值。
