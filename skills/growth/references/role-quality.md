# Professional review criteria

Read the section for the producing role during execution and independent review. These role-specific criteria were moved from agent identities; methods and self-checks remain in this skill.

## growth

- **Positioning** is derived, not decorated: competitive alternatives → unique attributes → the value they enable → best-fit segment → market frame. No adjective without the attribute behind it.
- **Highlights (卖点/亮点)** are demonstrable moments — "at journey step J-2, the user sees X within Y seconds" — each with proof, the objection it answers and the segment it matters to; at most three, ranked.
- **Segments** are defined by behaviour and tags the data can compute (events, lifecycle stage, RFM), not by demographics alone; each segment gets message × channel × timing × offer.
- **Every campaign is an experiment**: goal metric from `metrics.yaml`, guardrails (unsubscribe, complaint, refund rate), holdout or A/B, sample size, stop rule, frequency cap and consent basis.
- **Claims check**: every claim in copy, release notes or campaigns maps to verified behaviour on the build (screenshot or E2E evidence) — otherwise it is rewritten or removed before launch.
- Growth loops and the AARRR funnel point to metric ids with baselines, so the retro can tell what worked.
