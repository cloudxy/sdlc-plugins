# 定位：从竞争替代品推出来，不是用形容词装饰出来

定位回答一个问题：**当目标用户拿我们和他正在用的东西比较时，凭什么选我们？** 它是产品、设计、文案、渠道的共同前提——定位错了，卖点、页面、投放全部跟着错。

## 五要素（按顺序推导，顺序不能反）

| # | 要素 | 要回答的问题 | 证据从哪来 |
|---|---|---|---|
| 1 | 竞争替代品 | 没有我们时，用户**实际**怎么解决？（含 Excel、人工、外包、什么都不做） | `compete.md` 集合与现状、访谈、评论区 |
| 2 | 独特属性 | 我们有、替代品没有（或做不到同等程度）的能力是什么？ | 产品实测、`compete.md`「我们已有、他们没有」 |
| 3 | 价值 | 这些属性让用户**得到**什么可感知的结果？（省时、赚钱、少出错、被认可） | 用户原话、行为数据、可演示时刻 |
| 4 | 最佳人群 | 谁**最在乎**这个价值？（不是「所有人」） | `market.md` 分群、高频/高痛/已付费特征 |
| 5 | 市场框架 | 把自己放进哪个品类，让价值一眼被理解？ | 用户搜索词、竞品自我描述、渠道习惯 |

**判定一条定位是否成立：** 把产品名换成主要竞品的名字，这句话还成立 → 不是定位。

## 三种市场框架

| 框架 | 适用 | 风险 |
|---|---|---|
| 正面竞争（我们是更好的 X） | 品类成熟、用户已在比较、我们在关键属性上明显更强 | 要在对方主场赢，证明成本高 |
| 细分称王（面向 Y 人群的 X） | 某个人群的需求被通用产品忽视 | 天花板受人群规模限制 |
| 开创品类（一种新的做法） | 用户还没意识到可以这样做 | 教育市场成本高，必须有强证明 |

## 至少两个定位选项并比较

| 维度 | 选项 A | 选项 B |
|---|---|---|
| 目标人群 | | |
| 主要替代品 | | |
| 独特属性 → 价值 | | |
| 市场框架 | | |
| 最强证明（可演示时刻 / 数字） | | |
| 需要产品补什么才站得住 | | |
| 风险 | | |

推荐理由必须引用证据（竞品评论、市场数据、产品实测），不是「感觉更有冲击力」。

## 信息屋（message house）

```
伞形信息（一句话，≤20 字，说价值不说功能）
├── 支柱 1：<价值点>   证明：<可演示时刻 / 数字 / 案例>
├── 支柱 2：<价值点>   证明：<…>
└── 支柱 3：<价值点>   证明：<…>
地基：<信任要素：安全合规 / 客户背书 / 服务承诺>
```

每个支柱必须能对应到 `feature-map.md` 里的一条关键旅程，否则就是空话。

## ToC 与 ToB 的差别

| | ToC | ToB |
|---|---|---|
| 决策者 | 使用者本人，冲动 + 场景驱动 | 使用者 ≠ 买单者，理性 + 风险驱动 |
| 价值表达 | 情绪、身份、社交货币、立刻爽到 | ROI、风险降低、集成成本、合规 |
| 最强证明 | 30 秒内能自己体验到的时刻、口碑 | 同类客户案例、数字、试点结果 |
| 替代品 | 其他 App、线下行为、「不做」 | Excel、外包、内部系统、竞品 |

## 反模式

| 反模式 | 例子 | 修正 |
|---|---|---|
| 形容词堆砌 | 「简单、强大、智能的数据平台」 | 说出属性与价值：「导入表格 30 秒出第一份可分享的报表」 |
| 面向所有人 | 「适合所有企业」 | 选最在乎的人群，其他人群是溢出 |
| 抄竞品的自我描述 | 竞品说「一站式」，我们也说 | 从替代品的差评里找我们的机会 |
| 定位先于产品实测 | 宣称「实时」，实际延迟 5 分钟 | 定位只用已验证或本次一定交付的属性，其余标「假设」 |
| 只写一个选项 | 只有推荐，没有被否决的备选 | 至少两个选项，写清为什么否决 |
