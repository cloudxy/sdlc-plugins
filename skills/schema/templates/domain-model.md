## 5. 命名与建模规范

| 项 | 规范 |
|---|---|
| 表名 | 复数 snake_case；关联实体用业务名（`enrollments` 而非 `student_course`） |
| 主键 | `BIGINT` 代理键；业务唯一性用 UNIQUE 约束 |
| 租户 | 所有租户数据表带 `tenant_id NOT NULL`，唯一键与索引以其开头 |
| 时间 | `created_at` / `updated_at` 必有；业务时间单独字段（`paid_at`）；统一 UTC |
| 状态 | `VARCHAR` + 应用层校验 + 流转图；不用数据库 ENUM |
| 金额 | `DECIMAL(p,s)` + 币种字段 |
| 软删 | 按豁免矩阵；加软删的表唯一键包含删除标记 |
