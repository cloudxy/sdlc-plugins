# 视觉方向 — 反模板默认

> 为什么存在这个文件：AI 生成的设计会聚成几种"默认脸"。用户看到默认脸的结论不是"这个模型能力不行"，而是"这个设计没有为我的产品做过选择"。本文件是检测锚点 + 决策流程，来源为 Anthropic frontend-design skill（原件见 [vendor/anthropic-skills/skills/frontend-design/SKILL.md](../../../vendor/anthropic-skills/skills/frontend-design/SKILL.md)，由 plugin-updater 每日收纳，不在插件内另存副本）。

## 五个 AI 默认簇（自检锚点）

以下每一簇对某些 brief 都是合法选择，但**它们是默认而不是选择**——出现即说明你没有为这个 brief 做决策：

| # | 默认簇 | 特征锚点 |
|---|---|---|
| 1 | 暖奶油底 + 衬线 + 赤陶色 | 近 `#F4F1EA` 底、高对比衬线标题、近 `#D97757` 强调色（这是 Anthropic 自己的交互色，出现在别人家产品上就是 tell） |
| 2 | 近黑底 + 单一荧光强调 | 近黑背景 + acid-green 或 vermilion 一个强调色 |
| 3 | 报纸风 | 细线分隔、零圆角、密集多栏 |
| 4 | SaaS 卡片套件 | 内容切成一模一样的圆角卡片、所有元素同一个圆角半径、每张卡片同款 `rgba(0,0,0,.1)` 阴影、渐变色块当装饰 |
| 5 | 万物皆模板 chrome | 每个标题上方 ALL-CAPS eyebrow 标签；元信息用中点连接（`A · B · C`）；`WORD — fragment` 式破折号标签；近黑色（`#0B0B0B`/`#111`）冒充纯黑；小数据标签用等宽字体；链接按钮后缀 `→` |

## 两遍法：先计划，后实现

**第一遍只做计划，不写代码。** 计划四要素：

```
① 色彩：4-6 个命名的 hex 值（核心底色盘，不是完整 token 表）
② 字体：选了什么 family，各自承担什么角色
③ 布局：一句话概念 + ASCII 线框（用于对比取舍）
    含对齐决策：内容左对齐/居中/两端？
④ 原则：这个页面凭什么独特的三句话概括
```

**第二遍对照修订：** 把计划放到一边，问自己"如果给一个相似的产品做设计，我会不会得到差不多的方案？"——会，就改掉那部分，并写下改了什么、为什么。确认计划不是默认产物后才开始实现。

## 排版纪律

- 行长 < 80 字符；衬线正文可略长，行高给比无衬线更大一点
- 一个或两个 family；用两个时必须差异明显
- 三个最常见的排版 tell：**标题里只强调一个词**（斜体/变色）、**标签用全大写**、**内容上方加不必要的装饰性标签**
- 标题即视觉元素时，让字体处理本身参与设计，而不是当内容的中性载体

## 结构装置编码信息

描边、分隔线、编号、eyebrow、标签——它们应该**承载内容信息**，不是装饰。典型误用：`01 / 02 / 03` 序号标记很时髦，但只对真正的序列内容成立（步骤、时间线）；内容不是序列就别编号。

## 动效克制

- 非用户触发的动效只用于**引导注意力**：一个编排好的时刻（一次页面加载序列或一次揭示）胜过散落各处的效果
- 每节 fade-and-slide-up 入场 + 每张卡片 hover 过渡 = AI 默认脸
- 响应用户动作的动效（展开、确认）欢迎——它展示了什么变了
- 大幅动效必须可关：`prefers-reduced-motion`（见 [tokens-and-a11y.md](tokens-and-a11y.md)）

## 把大胆花在一处

让**一个元素**成为被记住的东西，周围一切保持安静克制；砍掉所有不服务 brief 的装饰。对照 Chanel 的建议：出门前照镜子，摘掉一件配饰。

## 项目落地：两类页面的差异化空间

| 页面 | 基础 | 你的自由度在哪 |
|---|---|---|
| **admin 后台**（antd 基座） | 组件结构、交互模式已被 antd 固定 | tokens（语义色/圆角/阴影/密度）、布局密度、状态设计质量、空态文案——差异体现在"契约质量"而非视觉花样 |
| **official 官网**（品牌前线） | 无组件库约束 | 全部自由度：字体个性、动效编排、结构装置——这里最需要两遍法，也最容易掉进默认脸 |

admin 页面强行做视觉差异化是负资产（用户每天用 8 小时，熟悉度 > 新鲜感）；official 页面长得像模板是负资产（唯一任务是让访客记住）。先判断页面属于哪类，再决定花多少力气在视觉上。

## 质量底线（不可谈判）

大胆的部分之下必须有无声的质量地板：响应式到移动端、键盘焦点可见、动效可关、对比度合规。底线项的完整清单与设计期验证方法见 [tokens-and-a11y.md](tokens-and-a11y.md)。

## 自检

- [ ] 计划四要素齐（色/字体/布局/原则），且在实现前完成
- [ ] 计划对照过五个默认簇，被命中的部分已修订并写下理由
- [ ] brief 明确指定的方向被严格执行（brief 的原话赢过一切，包括它要求默认脸时）
- [ ] 序号标记只出现在真序列上
- [ ] 非触发动效只有一个编排时刻
- [ ] 一个元素承载大胆，其余安静
- [ ] 页面已归类 admin/official，力气花对了地方
- [ ] 质量底线项全部达标（指针 tokens-and-a11y.md）
