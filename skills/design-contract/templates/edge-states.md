## 屏 1：工单列表

### 加载态

| 场景 | 表现 |
|---|---|
| **首次加载**（无数据） | 骨架屏：表头真实显示 + 8 行灰条占位，形状与真实行一致 |
| **筛选后重新加载**（有旧数据） | **保留旧列表**（半透明 0.6）+ 顶部细进度条；不变骨架 |
| 加载 < 200ms | 不显示加载态（避免闪烁） |
| 加载 > 10s | 显示「加载较慢，请稍候」+ [取消] |

**首次与刷新必须不同**：刷新时整屏变骨架，用户看着内容消失，体验上像崩了。

### 空态（两种，文案与操作都不同）

| 类型 | 判据 | 文案 | 操作 |
|---|---|---|---|
| **本来就没有** | 无筛选条件且结果为空 | 标题「还没有工单」<br>说明「工单会在客户提交后出现在这里」 | [了解工单流程]（次要按钮） |
| **筛选后没有** | 有筛选条件且结果为空 | 标题「没有符合条件的工单」<br>说明「当前筛选：状态=未结，本周」 | **[清除筛选]**（主按钮） |

插图：两种用不同插图（空文件夹 vs 放大镜）。

**不许用「暂无数据」糊过去**——新用户不知道该干什么，老用户不知道是筛选问题还是真没了。

### 错误态（按契约错误码逐个定义）

| 错误码 | 展示位置 | 文案 | 用户下一步 |
|---|---|---|---|
| 401 `UNAUTHENTICATED` | 全屏 | 「登录已过期」 | [重新登录]（自动跳转） |
| 403 `FORBIDDEN_SCOPE` | 内容区 | 「无权访问这些工单」 | [返回工作台] |
| 429 `RATE_LIMITED` | Toast | 「操作过于频繁，请 {n} 秒后重试」 | 自动倒计时后可重试 |
| 5xx | 内容区 | 「加载失败，请稍后重试」+ 小字「错误编号 {trace_id}」 | **[重试]**（主按钮） |
| 网络错误 | 内容区 | 「网络连接失败」 | [重试] |
| **未知错误码（兜底）** | 内容区 | 「加载失败，请稍后重试」+ trace_id | [重试] |

**兜底分支必须有**：后端可能新增错误码，没有兜底就是白屏。

**局部失败不整页报错**：列表加载成功但右侧统计卡失败 → 只有统计卡显示错误，列表照常。

### 权限态

| 场景 | 隐藏还是禁用 | 理由 |
|---|---|---|
| 客服看到「导出全组」选项 | **隐藏** | 不该知道有这个能力，避免无效申请 |
| 无导出权限的角色看导出按钮 | **禁用 + tooltip**「需要主管权限」 | 应该知道有这功能，可以去申请 |
| 无权限的行的勾选框 | 禁用 + 行尾小锁图标 | 让用户理解为什么选不了 |

**隐藏 vs 禁用是产品决策，由设计定并给理由。** 不要让 `/frontend` 替你决定。

前端权限判断只是体验优化，**后端必须独立校验**（这一点写在这里提醒 `/qa` 测第三类越权）。

### 边界态

| 边界 | 表现 |
|---|---|
| 工单标题超长（> 60 字符） | 单行截断 + `…` + hover tooltip 显示全文 |
| 负责人为空 | 显示 `—`（不是空白） |
| 列表极多（> 1000 条） | 分页；页码显示「1 2 3 … 50」 |
| 列表仅 1 条 | 正常显示（检查表格布局不塌陷） |
| 数字极大（金额 9999999.99） | 千分位分隔 `9,999,999.99` |
| 时间跨年 | 显示年份（`2025-12-31`），当年则省略年（`09-05`） |

## 屏 2：导出配置（弹窗）

### 加载态

| 场景 | 表现 |
|---|---|
| 打开弹窗时预估行数 | 行数处显示骨架条（宽度约 4 字符） |
| 点击确认后 | 确认按钮 disabled + 内部 spinner + 文案「导出中…」；**弹窗其余部分不禁用**（用户可以看配置） |

### 空态

➖ 不适用——弹窗内容为固定配置项，无数据依赖。

### 错误态

| 错误码 | 展示位置 | 文案 | 用户下一步 |
|---|---|---|---|
| 400 `INVALID_PARAM` | **对应输入项旁**（用 `field` 定位） | 后端 message | 修正该项 |
| 409 `EXPORT_IN_PROGRESS` | 弹窗顶部内联警告 | 「已有导出任务进行中」 | [查看进行中的任务]（链接） |
| 422 `ROW_LIMIT_EXCEEDED` | 弹窗顶部内联警告 | 「单次最多导出 {limit} 条，当前 {actual} 条」 | [关闭并缩小筛选范围]（关弹窗并聚焦筛选栏） |
| 5xx | 弹窗底部内联 | 「导出失败，请重试」+ trace_id | [重试]（不关弹窗） |
| 兜底 | 同 5xx | | |

**失败时不关闭弹窗，保留用户配置。** 关掉的话用户要重新勾选、重新配置——这是最招投诉的实现。

### 权限态

无导出权限时进不到这一屏（屏 1 已禁用入口）。若通过深链接进入 → 显示 403 全屏态。

### 边界态

| 边界 | 表现 |
|---|---|
| 可选列极多（> 20） | 列选择区固定高度 + 内部滚动 |
| 仅 1 列可选 | 正常显示，默认勾选 |
| 行数为 0（勾选的都被删了） | 弹窗顶部警告「所选工单已不存在」+ 确认按钮 disabled |

## 屏 3：进度与结果

### 加载态

| 场景 | 表现 |
|---|---|
| 进度条 | 显示百分比 + 已处理行数「12% · 2976 / 24800」 |
| 无法获知百分比时 | 不定式进度条 + 「正在导出…」 |
| 进度轮询中断（网络问题） | 保持上次进度 + 小字「连接中断，正在重连」 |

### 错误态

| 场景 | 文案 | 用户下一步 |
|---|---|---|
| 导出任务失败 | 「导出失败：{后端 error.message}」 | [重新导出]（带回原配置） |
| 文件已过期（> 7 天） | 「文件已过期」+ 说明保留期限 | [重新导出] |
| 部分失败（28/30 成功） | 「导出完成，2 条已被删除未包含在文件中」（警告色，非错误色） | [下载 28 条] + [查看详情] |

**部分成功用警告色不用错误色**——它是成功但有提示，不是失败。

### 边界态

| 边界 | 表现 |
|---|---|
| 极慢（> 5 分钟） | 「导出较慢，完成后会通知你」+ 允许离开页面 |
| 文件极大（> 100MB） | 下载前提示文件大小 |
| 同时多个导出任务 | 进度区显示多条，最新在上 |

## 通用规则

### Toast vs 内联 vs 全屏

| 严重度 | 用什么 |
|---|---|
| 成功提示 | Toast（3 秒自动消失） |
| 可恢复的操作失败 | 内联（就近显示，不自动消失） |
| 页面级加载失败 | 内容区替换 |
| 会话失效 | 全屏 |

### 错误文案三要素

```
① 发生了什么（用户能理解的话，不是技术术语）
② 为什么（如果有助于用户判断）
③ 现在能做什么（可操作的下一步）

❌ 「Error: 422 Unprocessable Entity」
✅ 「单次最多导出 10000 条，当前选中 10001 条。请缩小筛选范围后重试。」
```

### 不只靠颜色

所有状态都有**图标或文字**作为第二通道：错误 ✕ + 红色、警告 ⚠ + 黄色、成功 ✓ + 绿色。
