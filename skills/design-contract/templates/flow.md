## 屏 1：工单列表

| 项 | 内容 |
|---|---|
| **路由** | `/tickets?status=open&page=1` |
| **进入方式** | 主导航「工单」；或深链接（带筛选参数） |
| **主操作** | 筛选并选择要导出的工单 |

### 关键元素

| 元素 | 说明 |
|---|---|
| 筛选栏 | 状态多选、时间范围、负责人 |
| 列表 | 表格，含勾选列 |
| 全选 | 表头勾选框（全选当前页 / 全选所有匹配项——**两者要区分**） |
| 导出按钮 | 工具栏右侧 |

### 交互描述

**导出按钮**：

| 条件 | 状态 | 文案 | 说明方式 |
|---|---|---|---|
| 未勾选任何行 | `disabled` | 「导出」 | tooltip：「请先选择要导出的工单」 |
| 已勾选 n 行（n ≤ 10000） | `enabled` | 「导出 (n)」 | — |
| 已勾选 n 行（n > 10000） | `enabled` | 「导出 (n)」+ 警告图标 | tooltip：「超过 10000 条将转为后台导出」 |

**全选勾选框**：

| 操作 | 行为 |
|---|---|
| 点击表头勾选框 | 全选当前页；出现提示条「已选当前页 20 条，[选择全部 248 条]」 |
| 点击「选择全部」 | 选中所有匹配筛选的项；提示条变为「已选全部 248 条，[仅选当前页]」 |
| 修改筛选条件 | **清空选择**（因为匹配集变了）+ Toast 提示「筛选变化，已清空选择」 |

**筛选栏**：改变任一条件 → 列表重新加载（加载态见 edge-states）+ URL 同步 + 清空选择。

### 交互态（四态）

| 元素 | hover | focus | active | disabled |
|---|---|---|---|---|
| 导出按钮 | `color-primary-hover` | 2px `color-focus` 外环 | 轻微下沉 | `color-text-disabled` + tooltip 说明 |
| 表格行 | `color-surface-raised` | 行外框 | — | — |
| 勾选框 | 边框加深 | 外环 | — | 灰化（无权限行） |

### 离开方式

| 出口 | 去哪 | 本屏状态 |
|---|---|---|
| 点击导出 | 屏 2 | 保留（勾选、滚动位置、筛选） |
| 点击某行 | 工单详情 | 保留 |
| 切换导航 | 其它模块 | 不保留（重新进入时按 URL 恢复筛选） |

### 返回行为

从屏 2 取消返回：**勾选、滚动位置、筛选全部保留**。
从工单详情返回：同上（用户可能只是去确认某条工单的内容）。

## 屏 2：导出配置（弹窗）

| 项 | 内容 |
|---|---|
| **形态** | 弹窗（沿用现有约定，配置项少不值得单独页面） |
| **进入方式** | 屏 1 点击导出 |
| **主操作** | 确认格式与列 |

### 关键元素

| 元素 | 说明 |
|---|---|
| 标题 | 「导出 30 条工单」（带数量） |
| 格式选择 | 单选，本轮只有 CSV（**单选项时仍显示，为将来留位**） |
| 列选择 | 多选，默认勾选上次选择（熟练用户效率） |
| 行数提示 | 超过 10000 时显示「将转为后台导出，完成后通知你」 |
| 取消 / 确认 | 右下 |

### 交互描述

**列选择**：

| 条件 | 状态 |
|---|---|
| 至少勾选 1 列 | 确认按钮 `enabled` |
| 未勾选任何列 | 确认按钮 `disabled` + 旁注「请至少选择一列」 |

默认值：**上次使用的列组合**（本地记住）；首次使用时默认勾选「工单号/标题/创建时间/负责人」。

**确认按钮**：点击后立即 `disabled` + 内部 loading（防重复提交），文案变「导出中…」。

### Tab 焦点顺序

```
1. 关闭按钮（×）
2. 格式选择（单选组，方向键切换）
3. 列选择（Tab 进入组，方向键移动，Space 勾选）
4. 取消按钮
5. 确认按钮
→ 焦点锁在弹窗内（Tab 到最后回到第 1 项）
→ Esc = 取消
→ 关闭后焦点回到屏 1 的「导出」按钮
```

### 离开方式

| 出口 | 去哪 | 屏 1 的状态 |
|---|---|---|
| 确认 | 屏 3 | 保留勾选 |
| 取消 / Esc / 点击遮罩 | 屏 1 | **保留勾选与滚动位置** |
| 确认后失败 | 留在屏 2 + 内联错误（**不关闭弹窗，保留用户配置**） |

**失败时不关弹窗**是关键：关掉的话用户要重新勾选、重新配置。

## 屏 3：结果

三个分支：

### 分支 A：行数 ≤ 10000（同步）

```
弹窗关闭 → 浏览器开始下载 → Toast「导出成功，30 条」
屏 1 状态：保留勾选（用户可能要再导一次别的格式）
```

### 分支 B：行数 > 10000（异步）

```
弹窗关闭
→ 页面顶部出现进度条：「正在导出 24800 条… 12%」+ [查看详情]
→ 用户可继续操作页面（非阻塞）
→ 点击「查看详情」进入 /exports/:id
→ 完成时：进度条变「导出完成 [下载]」+ 站内通知
→ 失败时：进度条变错误态（见 edge-states）

关键行为：
- 用户离开页面再回来 → 进度从服务端恢复（不依赖前端内存）
- 用户关闭浏览器再打开 → 站内通知里能找到结果
- 文件有效期 7 天（NFR-06），过期后详情页显示「文件已过期，请重新导出」
```

### 分支 C：失败

见 `edge-states.md` 错误态，按契约错误码分。

## 首次使用 vs 熟练使用

| 项 | 首次 | 熟练 |
|---|---|---|
| 列选择 | 默认四列 + 弹窗内提示「可自定义导出列」 | 记住上次选择，无提示 |
| 全选 | 提示条说明「当前页 / 全部」的区别 | 同样显示（信息本身有用） |
| 破坏性操作 | — | **确认不跳过**（本流程无破坏性操作） |
